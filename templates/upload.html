🛡️ Sender Cryptographic Pipeline

Here is the exact sequence of cryptographic algorithms that will execute when you submit:

1. SHA-256 Digest
Computes the hash digest of the original file bytes before encryption.
2. AES-256-GCM Encryption
Generates a fresh 256-bit random AES key & 96-bit nonce. Encrypts payload and outputs a 128-bit authentication tag.
3. RSA-2048 OAEP Key Encapsulation
Encrypts the symmetric AES key using the recipient's RSA public key with SHA-256 OAEP padding.
4. RSA-PSS Digital Signature
Signs package metadata with sender's RSA private key to guarantee authenticity and non-repudiation.
