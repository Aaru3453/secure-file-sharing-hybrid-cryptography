Secure File Sharing System Using Hybrid Cryptography

Combines the blistering computational speed of symmetric encryption (AES-256-GCM) with the robust key distribution of asymmetric cryptography (RSA-2048 OAEP), guaranteed by SHA-256 integrity checks and RSA-PSS digital signatures.

1. AES-256-GCM

Galois/Counter Mode (GCM): Encrypts the raw file payload. Generates a fresh random 256-bit symmetric key and a unique 96-bit nonce for every file, yielding high throughput and a 128-bit authentication tag.

🔑

2. RSA-2048 OAEP

Optimal Asymmetric Encryption Padding: Encapsulates the 256-bit AES key using the recipient's RSA public key. Only the intended receiver can decrypt the AES key with their private key.

#️⃣

3. SHA-256 Digest

Cryptographic Hash: Calculates a deterministic 256-bit hash over the plaintext file prior to encryption. Recomputed post-decryption to guarantee 100% bit-level data integrity.

✍️

4. RSA-PSS Signature

Probabilistic Signature Scheme: Sender signs the file hash and transfer metadata using their RSA private key. Guarantees message authenticity and legal non-repudiation.

⚙️ End-to-End Hybrid Transmission Pipeline

Sender Workflow (e.g., Alice)
  1. Select recipient and upload file.
  2. Compute original file's SHA-256 hash.
  3. Generate fresh random AES-256 key & 96-bit Nonce.
  4. Encrypt file data using AES-256-GCM (produces ciphertext + auth tag).
  5. Encrypt AES key with recipient's RSA-2048 public key using OAEP.
  6. Create digital signature using sender's private key using RSA-PSS.
  7. Store ciphertext in storage/encrypted/ and metadata in SQLite.
Receiver Workflow (e.g., Bob)
  1. Login and open Received Files dashboard.
  2. Select encrypted file package to verify & decrypt.
  3. Decrypt AES key with receiver's RSA-2048 private key (OAEP).
  4. Decrypt ciphertext using recovered AES key, Nonce & Tag (AES-256-GCM).
  5. Verify sender's digital signature using sender's RSA Public Key (RSA-PSS).
  6. Recompute SHA-256 on decrypted data and compare against original digest.
  7. If all checks pass, download the verified original plaintext file.
